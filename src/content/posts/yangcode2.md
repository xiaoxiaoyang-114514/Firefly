## 前言

Yangcode2是用Scratch（Turbowarp）开发的一个**伪**编程语言，仅供娱乐用途，补药当真（



## 代码基本结构

```Yangcode2
a;
b;
c;
d {
	e;
};
```

这是Yangcode2代码的基本结构。换行时需要加分号`;`(**半角**)；在后花括号`}`后面**一定一定**要记得加分号`;`！这和很多语言都不一样。

Tip: 在Yangcode2中，缩进（四个空格）和换行都是可选的。你不要也可以。

## 变量



### 变量的赋值

在编写代码时常常需要用到变量。变量的创建和更改值都需要用到`var`关键词来实现，就像下面一样：

```Yangcode2
var a = 0;
var a = 5;
```

这条代码先是创建了一个`a`变量，并将其赋值为`0`；接着第二行代码将变量`a`的值更改为了`5`。也就是说这条代码执行完成后a的值最终会是5.

### 变量的调用

现在我们的变量有了自己的值，但是要怎么拿出来用呢？可以在需要变量值的位置使用`&<变量名>`，按上面的例子来说就是`&a`

(两边**一定一定**是空格，比如可以是`&a + 1`,而不是`&a+ 1`，Yangcode2会把同一空格内`&`后面的部分**全部**识别为变量名)

可以把上面的例子加一行代码，变成这样：

```Yangcode2
var a = 0;
var a = 5;
print &a;
```

现在就可以看到打印了一个5.

当然，var 后面的`=`后面可以写一个表达式，如下：

```Yangcode2
var a = 4;
var a = &a + 1;
print &a;
```

依旧会输出5.





## if条件判断

在编写代码的时候，我们常常需要通过判断来让代码知道这段执不执行，那段运不运行。这个时候就要用到if。使用方法很简单，先看看示例代码。

```Yangcode2
var a = 0;
if &a == -1 {
	print ?;
};

if &a == 0 {
	print ok;
};
```

运行这行代码会看到输出的`ok`。为什么没有看到`?`，这是因为`&a == -1`的布尔表达式的运算结果为False,代码会自动跳转至这个if对应的后花括号处(`}`)

现在不妨来写一点复杂的程序：

```Yangcode2
var a = 5;
if (&a > 0) && (&a < 10) {
	print ok;
};
if (&a > 0) || (&a > 100) {
	print ok;
};
```

可以看到两个`ok`，这是因为5既大于0又小于10,满足第一个“与`&&`”的条件；5虽不大于100但大于0, 满足第二个“或`||`”的条件。

***给开发者的一个小提示***：

​	if原理是如果表达式计算为false即跳转到对应花括号，若为true**或Error（计算错误）都**会运行后面的代码



## 列表

在很多编程语言中都有“数组”的概念，近似的在Yangcode2中也有类似相似like的东西，我们称其为“列表”。



### 普通列表

普通列表一旦创建便无法更改大小，但可以更改数据。代码如下：

```Yangcode2
list a [
	a,
	b,
	c
];

```



这条代码创建了一个静态列表a,有三个项为abc.想要读取列表的某个项，需要用到`$`,即

```Yangcode2
$<列表名>.<下标>
```

注意，**下标从0开始**，用刚刚的例子来说，`$a.0`=a,`$a.2`=c

如果想要更改列表里的某个特定项，需要用到`set_list`。

```Yangcode2
list a [a,b,c];
set_list a.1 = c;
```

这段代码结束后，列表a的所有项为 a c c.



### 动态列表

在Yangcode2中还有一种列表，创建时无需赋值，可以更改大小，可以更改数据，这就是动态列表。

对于动态列表的操作有统一的关键词`dynlist`。具体方法如下：(仅文本不是代码！这玩意只是讲用法不是运行)

```plaintext
dynlist new a;   ->创建动态列表a
dynlist push a 1;  ->在动态列表a末尾追加项，值=1
dynlist pop a;   ->删除动态列表a的末尾项
dynlist remove a 4 ->删除动态列表a的下标4项（下标自动变化）
dynlist insert a 3 abc;  ->在动态列表a的下标3前插入abc,现在下标3为abc
dynlist set a 2 abc;   ->将动态列表a的下标2的项替换为abc
```



动态列表看似难以理解，但和Scratch的列表大差不差，多试试就很容易学会了。(~~其实就是懒得写教程啦喵~~)
调用和静态列表类似，为`@<name>.<xxx>`.





## 循环相关

在Yangcode2中有两种循环：`loop`  `while`.



### loop循环

loop循环很简单，即死循环，适合于那些需要一直迭代运算或用户交互（没做输入喵...）的时候。

```Yangcode2
loop {
	print a;
};
```

代码会一直输出a.



### while循环

在其他编程语言中也有while循环，逻辑是**如果其后的表达式成立则一直执行，若不成立则停止循环**，**如果在循环途中不成立则循环完后停止**

即 ***每次循环和开始循环时判断***

```Yangcode2
var a = 0;
while &a < 20 {
	print &a;
	var a = &a + 1;
};
```

这段代码会连续输出0 -20.



### sleep等待

用下面的代码可以等待一段时间（ms）

```Yangcode2-example
sleep <xxx>;
```

如:

```Yangcode2
sleep 1000;
```
